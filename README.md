# Conta Bancária - Exceções Personalizadas

Projeto em Java demonstrando o uso de exceções personalizadas (custom exceptions) para validação de regras de negócio em operações bancárias.

## 🚀 Conceitos aplicados
- Criação de `SaldoInsuficienteException` extends `RuntimeException`
- Uso de `throw` para lançar exceção de regra de negócio
- Uso de `try/catch` para tratar erro sem quebrar a aplicação
- Diferença entre `RuntimeException` vs `Exception`
- Validação com `IllegalArgumentException`

## 💻 Como rodar
```bash
javac *.java
java Main
